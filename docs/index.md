# Building Neural Networks

Workshop materials for building neural networks with PyTorch, adapted from the [USC CARC Building-NeuralNetworks repository](https://github.com/uschpc/Building-NeuralNetworks).

!!! info "About this site"

    This documentation site converts the original workshop materials (Jupyter notebook, setup scripts, and slides) into a clean, searchable Zensical format for easier reference.

## Workshop Overview

This workshop covers the fundamentals of building and training a simple neural network using PyTorch and the FashionMNIST dataset.

### What you'll learn

- Setting up a Conda environment on CARC systems
- Loading and preparing image datasets with TorchVision
- Defining a neural network architecture with `nn.Module`
- Training a model with a loss function and optimizer
- Evaluating accuracy and saving/loading models

## Quick Start

1. [Set up your environment](setup.md) on CARC
2. Follow the [PyTorch tutorial](tutorial.md) step by step
3. Review the [slides and original resources](resources.md)
